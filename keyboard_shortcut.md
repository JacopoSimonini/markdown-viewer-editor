# Keyboard Shortcuts — Markdown Editor

## File
| Shortcut | Action |
|---|---|
| `Ctrl + N` | New file |
| `Ctrl + O` | Open file |
| `Ctrl + S` | Save |
| `Ctrl + Shift + S` | Save As… |

## Formatting (in the editor)
| Shortcut | Action |
|---|---|
| `Ctrl + B` | Bold |
| `Ctrl + I` | Italic |
| `Ctrl + H` | Heading |
| `Ctrl + K` | Insert link |

## View / Layout
| Shortcut | Action |
|---|---|
| `Ctrl + 1` | Split view |
| `Ctrl + 2` | Editor only (focus) |
| `Ctrl + 3` | Preview only |
| `Ctrl + Shift + T` | Toggle light/dark theme |

## Zoom
| Shortcut | Action |
|---|---|
| `Ctrl + +` | Zoom in |
| `Ctrl + -` | Zoom out |
| `Ctrl + 0` | Reset zoom to 100% |
| `Ctrl + mouse wheel` | Zoom in/out |

## Other (standard)
| Shortcut | Action |
|---|---|
| `Ctrl + Z` / `Ctrl + Y` | Undo / Redo |
| `Ctrl + F11` | Toggle fullscreen |
| `Tab` | Indent (in editor) |

## Mouse-only
- **Toolbar buttons**: B / I / H / List / Link / Code (note: **List** has no keyboard shortcut)
- **Scroll-sync pill** (→ / ←) on the divider in Split mode
